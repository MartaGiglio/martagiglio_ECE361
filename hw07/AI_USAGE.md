# AI Usage

I used ChatGPT as a learning and debugging assistant while working on this assignment.

AI assistance was used to:
- Understand dynamic memory allocation with `malloc`, `realloc`, and `free`.
- Review the stack ADT implementation and its functions.
- Understand the logic of the bracket checker.
- Debug test failures and create regression tests.
- Understand AddressSanitizer and UndefinedBehaviorSanitizer reports.
- Organize the Makefile and project documentation.

I reviewed, tested, and ran the code in my own development environment. I also used the sanitizer experiments to understand common memory errors.
