# HW3 - Pointers

## Description

This project implements four functions using pointers:
- `swap_float`: swaps two float values.
- `minmax`: finds the minimum and maximum values in an array.
- `find_above`: returns a pointer to the first element greater than a threshold.
- `reverse`: reverses an array in place.

## Compilation

To compile the project, run:

```bash
make
```

## Tests

To run the tests, execute:

```bash
make test
```

The test suite checks normal cases, edge cases, and NULL pointers.

## Clean

To remove generated files, run:

```bash
make clean
```
