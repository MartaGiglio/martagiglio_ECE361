# AI Usage

AI assistance was used during the development of this assignment.

The assistance included:
- Understanding the requirements for the pointer functions.
- Reviewing the functions in `ptr.c`.
- Creating tests for normal cases and edge cases in `tests/test_ptr.c`.
- Debugging compilation errors and warnings.
- Preparing the `Makefile` and `README.md`.

The code was compiled using GCC with the flags `-std=c11 -Wall -Wextra -Wpedantic`.

The tests were run using `make test`. All 15 tests passed.

The final code and test results were checked in the terminal.
